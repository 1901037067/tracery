# 双链与反链

双链（`[[双向链接]]`）是 Obsidian 的灵魂：**用链接把笔记织成网络，而不是困在文件夹树里**。

## 怎么写双链

直接输入双方括号就会触发链接：

```
[[笔记名]]              → 链接到「笔记名」
[[笔记名|显示别名]]      → 链接过去，但显示成别名
[[笔记名#标题]]          → 跳转到那篇笔记的指定标题
[[文件夹/笔记名]]        → 按路径链接
```

## 链接是怎么解析的

Tracery 复刻了 Obsidian 的解析规则：

1. **先按路径**：`[[项目/Tracery 复刻计划]]` 直接找这个文件
2. **再按文件名**：`[[欢迎]]` 会在全仓库找名叫「欢迎」的笔记
3. **唯一才解析**：如果两篇笔记重名，链接显示为**未解析状态**（灰色虚线），点击后可以现场创建

> [!info] 关于重名
> Obsidian 的规则是「最短路径唯一匹配」。本复刻版采用「全局文件名唯一匹配」，行为一致。

## 反链面板

打开任意笔记，看右侧 **反向链接** 面板——所有链接到当前笔记的笔记都会列在这里，还带上下文行。比如你现在看到的这篇，被这些笔记引用：

- [[欢迎使用 Tracery]]（在上手指引里）
- [[Markdown 语法]]（在「链接」一节里）

## 未解析链接

输入一个还不存在的链接，它会显示为灰色。点击它，Tracery 会问你要不要当场创建这篇笔记——这是 Obsidian 的「链接先行」工作流：先织网，再填内容。

比如 [[还没想好写什么]] 这篇笔记并不存在，它显示为灰色虚线，点它就可以当场创建。
