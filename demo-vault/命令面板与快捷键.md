# 命令面板与快捷键

Obsidian 的高效来自于「双手不离键盘」。Tracery 复刻了最常用的那一批。

## 快捷键一览

| 快捷键 | 功能 |
|---|---|
| `Ctrl+P` | 命令面板（快速跳转笔记 + 执行命令） |
| `Ctrl+Shift+F` | 全局搜索 |
| `Ctrl+N` | 新建笔记 |
| `Ctrl+E` | 切换 实时预览 / 源码模式 |
| `Ctrl+B` / `Ctrl+I` | 加粗 / 斜体 |
| `Ctrl+S` | 手动保存（其实自动保存早就存了） |
| `Ctrl+K` | 插入 `[[双链]]` |
| `Ctrl+\` | 折叠 / 展开左侧栏 |
| `Ctrl+Shift+\` | 折叠 / 展开右侧栏 |
| `Enter` | 在列表 / 引用里智能续行 |
| `Tab` | 列表项缩进 |

## 命令面板

按 `Ctrl+P`，输入任何东西：

- 输入**笔记名** → 模糊匹配，回车跳转（Obsidian 最常用的操作）
- 输入**命令名** → 比如「主题」「图谱」「新建」

## 实时预览 vs 源码模式

- **实时预览**（默认）：Markdown 语法直接渲染成样式，光标所在行才显示语法标记
- **源码模式**：纯文本编辑器，直接看 Markdown 源码

按 `Ctrl+E` 随时切换。当前状态显示在底部状态栏。

## 搜索

`Ctrl+Shift+F` 聚焦左侧搜索面板，输入关键词，结果按**文件名匹配优先 + 内容行匹配**排序，点击结果直接跳转。

试试搜「双链」，看看能命中几篇。
