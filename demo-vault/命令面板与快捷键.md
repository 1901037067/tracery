# 命令面板与快捷键

按 Ctrl+P 打开命令面板，输入笔记名称快速打开；输入 > 可以查找可执行命令。

## 常用默认按键

| 操作 | 按键 |
| --- | --- |
| 快速打开 / 命令面板 | Ctrl+P |
| 设置 | Ctrl+, |
| 新建笔记 | Ctrl+N |
| 全文搜索 | Ctrl+Shift+F |
| 切换实时预览 / 源码 / 阅读 | Ctrl+E |
| 加粗 / 斜体 / 删除线 | Ctrl+B / Ctrl+I / Ctrl+S |
| 插入双链 | Ctrl+K |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z，也支持 Ctrl+Y |
| 关闭当前标签页 | Ctrl+W |
| 新建绘图 | Ctrl+Shift+D |

macOS 使用 Cmd 替代 Ctrl。笔记会自动保存；Ctrl+S 的默认用途是删除线。立即保存命令也可以自行绑定。

## 修改按键

设置 → 快捷键：搜索命令，点击当前按键并按下新组合。冲突时会提示，Esc 取消录制。支持清除、单项还原和恢复全部默认，重启后仍会保留。

更多操作可以从 [[欢迎使用 Tracery]] 开始，也可以试试 [[双链与反链]] 和 [[图谱视图]]。
