# 欢迎使用 Tracery

这是你的本地笔记空间。一个文件夹就是一个笔记库，正文保存为 Markdown 文件，附件也在自己的电脑上。

> [!tip] 从一篇自己的笔记开始
> 点击左栏上方的 ＋ 或按 Ctrl+N，写下今天想记住的一件事。

## 找到需要的内容

- 左栏的叠页、星星、时钟分别是笔记库、收藏、最近打开。
- 右键笔记可以收藏、重命名或移入回收站；右键笔记库空白处可以新建笔记和文件夹。
- Ctrl+P 快速打开笔记或执行命令；搜索图标可以全文查找。
- 右栏默认显示大纲，也可切换关联和信息，查看链接、标签与历史版本。

## 试试常用写法

用 **粗体** 标出重点，用 *斜体* 补充说明，用 ==高亮== 留下提醒。

- [ ] 新建自己的第一篇笔记
- [ ] 用 [[双链与反链]] 把两篇笔记连接起来
- [x] 打开示例笔记库

| 想做什么 | 去哪里看 |
| --- | --- |
| 快速打开与自定义按键 | [[命令面板与快捷键]] |
| 给笔记分类 | [[标签系统]] |
| 看笔记之间的关系 | [[图谱视图]] |

## 保存与备份

停止输入后会自动保存，留意底部的保存状态。重要笔记请定期复制整个笔记库和附件到另一块磁盘；回收站和历史版本不能代替整库备份。

## 手机查看

让手机和电脑连到同一可信局域网，保持电脑运行 Tracery、不休眠。点击左侧底部的手机图标，用手机浏览器打开显示的地址。

当前手机网页可以读写电脑的笔记库；电脑关闭或离开同网后，不能继续浏览整库。普通网页访问、PWA 安装和完整离线笔记库是不同能力。
