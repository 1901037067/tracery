# 自托管同步服务

这是可选的笔记同步服务。单机写笔记、同网手机访问和内置局域网共享均不需要额外部署它；无需购买服务器或域名。

## 从源码启动

安装 Node.js 20 或以上版本，下载并解压 Tracery 源码，在项目根目录运行：

~~~sh
node sync-server/index.js --port 9600 --data ./sync-data --name 我的同步服务
~~~

启动后终端显示实际服务地址和配对码。在客户端“设置 → 同步”填写地址、配对码及设备名称。服务需要持续运行；保持数据目录可写，勿把它放进正在同步的笔记库。

可选端到端加密在客户端设置，操作与密码管理见 [同步指南](../docs/SYNC.md)。未开启加密时，服务端存储普通文件内容；开启后服务端存储密文。本机笔记不因此加密。

## 备份与恢复

停止服务后复制完整数据目录，包括 config.json。恢复时停止服务，把备份放回指定数据目录后重新启动。配置含设备凭据，请妥善保管。同步会传播删除，另行保留笔记库备份。

## 排障

- 无法启动：检查 Node 版本、端口占用、数据目录权限。
- 无法连接：确认地址不是客户端自己的 localhost，检查主机运行状态和私有网络防火墙设置。
- 配对失败：使用终端当前显示的配对码，不要将服务端配对码与内置共享六位码混用。
- 密码错误或需要解锁：在客户端输入原加密密码；服务端不能找回密码。

HTTP 仅限可信网络使用。需要经过不可信网络连接时，为同步服务配置 HTTPS 或可信 VPN，勿公开配对码和数据目录。这是同步入口，不是用手机浏览笔记的网页入口。
