# Tracery

开源的本地 Markdown 笔记软件。一个文件夹就是一个仓库，笔记和附件保存在自己的电脑里，无需云账户、付费服务器或域名。

支持实时预览、双链与反链、搜索、标签、大纲、绘图、图谱、历史版本与回收站；可在同一局域网内用手机浏览器访问电脑上的笔记。

## 下载与运行

1. 从 [GitHub Releases](https://github.com/1901037067/tracery/releases) 下载 Windows 64位包。
2. 解压整个文件夹，双击 `Tracery.exe`。保留旁边的 `resources` 和 DLL 文件，不能只复制一个 exe。
3. 首次启动会打开演示仓库。点左上角仓库名称进入管理入口，选择自己的普通文件夹作为笔记仓库。

Windows 包自带运行时，不需要安装 Node 或 Electron。当前预编译包面向 Windows 10/11 64位；其他平台可使用源码运行。

源码运行需要 Node 20及以上版本：

```sh
npm install
npm start
```

浏览器打开 `http://localhost:9520`。如需桌面窗口，使用 `npm run start:electron`。桌面程序会自动启动本机服务，不要另开同端口的源码实例。

## 笔记与侧栏

编辑区上方显示当前文档路径。图片与 PDF 在文件列表右侧标注类型；普通删除直接移入回收站，彻底删除时再确认。

设置 → 通用可导出、导入当前仓库的历史备份。历史备份包含旧正文，但不包含当前笔记和附件，请同时备份仓库文件夹；跨位置导入只关联当前正文与相对路径匹配的笔记。

- 左栏叠页、星星、时钟分别切换笔记库、收藏、最近打开。右键笔记可加入收藏，列表按仓库保存。
- 左栏第二行提供新建、折叠、排序和更多操作。排序支持文件名、编辑时间、创建时间的正反序，按笔记库保存；文件夹优先，时间缺失的文件按名称排在末尾。右键目标显示描边，不会因此打开文件。
- 顶部“＋”、`Ctrl+N`、笔记库空白处右键菜单均可新建笔记；空白右键或“更多”菜单也能新建文件夹、打开回收站及定位当前笔记。
- 右栏默认显示大纲，点击标题定位到对应章节。切换“关联”查看反链和出链；信息图标提供路径、修改时间、大小、标签和历史版本。
- 文件列表显示 Markdown/文本笔记、图片和 PDF。普通笔记只显示名称，PDF 带类型标记；PPT、Word、Excel、CSV、压缩包等暂不支持查看的文件会隐藏，原文件不会删除，仍参与原有仓库同步。
- `[[笔记名]]` 创建内部链接，`[[路径|别名]]` 显示别名。不存在的笔记经确认后创建；同名文件优先使用完整相对路径区分。
- 路径双链支持 `[[项目/计划]]`、`[[./同级笔记]]`、`[[../资料/笔记.md#章节|说明]]`；未明确路径且有多篇同名文件时不会任意跳到其中一篇。
- 标签头随数量自动压缩，不横向滚动。末尾「＋」打开空白标签页，选择或新建笔记后填入该页；「＋」与下拉按钮之间保留桌面拖窗空区。标签较多时可用下拉列表查看完整名称并切换。
- 右键标签可新建彩色分组或移入已有分组；点击组名折叠 / 展开，右键组名可改名、选色、在组内新开标签、取消或关闭分组。支持拖动标签移入 / 移出分组和整组换序，分组与空白标签按仓库保存在本机。关闭分组不会删除笔记文件。
- 拖动标签或整组时，会显示插入标记、相邻标签让位和“松开后”的排列预览；松手才保存新顺序，拖出标签栏或取消则保持原顺序。
- 右键顶部组名选择“保存分组”，即可把名称、颜色和笔记列表保存到左栏的“分组”页。展开查看或打开单篇笔记，点击“全部打开”恢复整组；再次保存可更新列表。已经属于其他组的标签会保留原归属，失效笔记会显示提示。分组记录按仓库保存在此设备，关闭标签不影响记录；“移除”只移除这份记录。
- 最左导航的命令按钮可打开命令面板，执行命令或搜索笔记，也可使用Ctrl+P（快捷键可修改）。
- 源码、实时预览、阅读三种模式共用同一份正文。行号与正文一起居中，不随宽窗口分离；可在设置中关闭行号。
- 关闭所有标签或未打开笔记时显示空白起始页，可新建笔记或快速打开已有笔记；按钮旁显示当前设置的快捷键。
- `[显示文字](https://example.com)` 在实时预览和阅读模式中显示为带外链图标的可点击文字；光标进入该行可编辑链接源码。
- 粘贴或拖入附件时，按设置保存到指定文件夹、当前笔记目录或仓库根目录。支持图片与PDF查看，绘图可保存为PNG并保留可再次编辑的场景文件。
- PDF 在主编辑区的标签页中打开，可与笔记切换、关闭和刷新恢复；从文件树、收藏或正文附件条点击即可查看，也可选择“外部打开”。打开前会保存当前笔记，保存失败时保留当前内容。
- 绘图画板保留顶部标签栏和最左导航栏，工具条、图片库与样式悬浮在画布上；右上角箭头可收起功能区。通过主导航或标签页离开时，未完成绘图先保留在本机图片库中。
- 工具条完整展示按钮，窗口较窄时自动换行，不使用横向滚动条。按住左侧点状手柄可拖动工具条，双击手柄回到默认位置。「颜色与样式 → 画板背景」可选点阵、网格线或空白，随草稿和场景保存；这些参考背景不出现在导出的白底 PNG 中。
- 绘图保留原始预设颜色，也可打开选色板或输入 `#RRGGBB` / `#RGB` 色号。描边与图形背景共用最近 8 个颜色，保存在本机，重启后仍可使用。

## 实时预览与公式

实时预览支持 `<u>下划线</u>`、带背景和语言标识的代码围栏、带层级竖线的嵌套引用。代码块在预览中仍能直接编辑；四个反引号可包住含三个反引号的代码示例。

数学公式支持行内 `$E=mc^2$` 与独立一段的 `$$…$$`（可跨行）。公式引擎和字体随软件保存，离线可用；实时预览点击公式回到源码编辑。公式语法以 [KaTeX 支持范围](https://katex.org/docs/supported.html) 为准，错误公式会保留原文提示。

## 嵌入笔记

在独立的一行输入 `![[`，选择笔记或附件，用方向键选择、Enter 确认。支持 `![[资料/笔记]]` 嵌入整篇、`![[资料/笔记#章节]]` 嵌入某标题及其子章节、`![[资料/笔记#^block-id]]` 嵌入指定文本块。给原文段落末尾加上 `^block-id` 即可作为文本块引用；列表等多行内容可在其后空一行单独写块标记。输入 `#` 选择标题，输入 `#^` 选择文本块，`|别名` 可修改卡片标题。

嵌入卡片中可滚动查看完整内容，点击右上角箭头打开原笔记，点击「编辑引用」修改引用语法；源码模式直接编辑 `![[…]]`，阅读模式只显示预览。嵌入中的图片和双链按原笔记路径解析；嵌套笔记引用显示为可打开的链接，不递归展开。引用不存在时显示提示，修改原文件后预览会刷新。
- 图谱以鼠标位置为缩放中心；缩小到一定比例后隐藏名称，放大后恢复。手动缩放后不会再次自动适配画面。

## 保存与恢复

状态栏显示未保存、保存中或保存失败；保存成功后才显示“已保存”。保存失败时，切换笔记、关闭当前标签和桌面退出会等待处理，顶部提示可重试保存、查看磁盘版本或将当前内容另存副本。

在外部编辑器或另一个窗口修改同一篇笔记后，旧版本的编辑内容不会直接覆盖磁盘；请根据提示选择保留方式。“查看磁盘版本”会先把当前未保存内容保留到恢复中心，再显示磁盘内容；“另存副本”创建独立笔记，保留原文件。

在命令面板搜索“恢复中心”，可以预览此设备当前仓库的未保存内容、导出文字、另存为笔记或移除记录。重新打开笔记时选择暂不恢复，旧草稿仍留在恢复中心。草稿保存在当前设备的浏览器/应用数据中；清除这些数据会移除草稿，重要内容请另存或导出。版本历史和回收站继续用于恢复已落盘的内容。

## 布局设置

在“设置 → 布局”调整主侧栏与辅助侧栏的宽度、正文行高和正文顶部留白，修改即时预览并自动保存在本机。直接拖动侧栏边界也会更新这份设置，双击边界恢复该区域默认宽度；交换位置后，宽度仍跟随原区域。字号、正文宽度仍在“编辑器”中调整。

两侧栏的文档库、星标、最近、分组、大纲、关联和信息都使用图标页签。按住图标拖到另一侧可换栏，拖到其他图标前后可排序；空侧栏也能接收图标。右键图标可移动或调整顺序，也可在布局设置中选择位置和点击上下按钮。键盘聚焦图标后，Alt+左右键排序，Alt+Shift+左右键换栏，普通方向键切换当前侧栏的页签。文档库的新建、排序和右键操作会跟随移动。

桌面可交换完整的主/辅助侧栏，分别展开或收起，也可隐藏最左功能栏、底部状态栏。标题栏的左右按钮控制当前对应一侧，展开状态会保存。布局设置统一在“设置 → 布局”中调整；功能栏隐藏后可从标签页列表下拉菜单选择“打开设置”，或在命令面板中搜索“布局设置”。“恢复默认布局”恢复默认页签位置、区域显隐和布局参数，保留主题、快捷键及笔记内容。

在“设置 → 布局 → 工作区”保存“上课”“复习”“写作”等快照，包含打开的笔记、活动标签、标签分组及颜色、侧栏位置与当前页签，以及各篇已浏览笔记的阅读位置和模式。选择后点击“切换”，或在顶部标签列表下拉菜单直接选择工作区，即可恢复。切换前会保存当前笔记；保存失败时保留当前内容，暂不切换。缺失笔记会跳过并提示。

工作区按笔记库保存在此设备；保存同名工作区会更新快照，移除不会关闭笔记或删除文件。可以导出或导入 JSON，文件只包含笔记相对路径和界面状态，不包含正文、绝对仓库路径或附件；导入后点击“切换”才生效，需在包含相同相对路径笔记的库中使用。旧布局预设会保留为“仅布局”工作区，也支持导入旧布局 JSON；保存同名工作区可补入当前笔记和阅读位置。侧栏“保存分组”仍用于单独收藏和恢复某个标签组。

设置中的下拉选单跟随明暗主题，可用方向键选择、Enter 确认、Escape 收起；页签位置选单使用相同操作。

窄窗口会自动收窄侧栏，为正文留出空间；手机保持主栏在左、辅助栏在右的抽屉，不受桌面整栏换边和收起设置影响。单个图标的位置仍会保留，文档库移动后，文件入口会打开它所在的抽屉。旧版本拖动过的栏宽会在首次使用新布局设置时迁移。

## 快捷键设置

点左下角设置图标，进入“快捷键”。可以搜索命令，点击当前按键录制新组合；冲突时会提示，Esc取消录制。支持清除、单项还原和恢复全部默认。

修改立即生效并保存在本机，重启后保留。旧绑定不再触发对应命令。编辑命令仅在笔记编辑区生效，输入框和绘图画布保留各自的基础编辑行为。

常用默认键：

| 操作 | 默认快捷键 |
|---|---|
| 命令面板 / 快速打开 | Ctrl+P |
| 设置 | Ctrl+, |
| 搜索 | Ctrl+Shift+F |
| 新建笔记 | Ctrl+N |
| 切换编辑模式 | Ctrl+E |
| 新建绘图 | Ctrl+Shift+D |
| 加粗 / 斜体 / 删除线 | Ctrl+B / Ctrl+I / Ctrl+S |
| 插入双链 | Ctrl+K |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z（也支持Ctrl+Y） |
| 下一个 / 上一个标签页 | Ctrl+Tab / Ctrl+Shift+Tab |
| 左 / 右侧栏 | Ctrl+反斜线 / Ctrl+Shift+反斜线 |

macOS上使用Cmd替代Ctrl。立即保存、手机访问、图谱、导出等无默认绑定的命令，也可以在此设置。部分系统或浏览器保留键不能绑定。

## 手机访问与局域网同步

以下授权流程适用于当前源码；已发布的 v1.11.0 ZIP 尚不包含本轮更新。

默认仅电脑本机可访问。手机和电脑连接同一个可信局域网，在电脑点击左侧导航底部的手机图标，选择新会话的「只读」或「读写」权限并开启访问。复制界面显示的地址，在手机浏览器输入当前 6 位通行码；手机默认端口为 9521（桌面端口加一），不要沿用桌面的 9520。开启、关闭和重启后重新开启均保持端口；端口被占用时会报错，不自动更换浏览器存储来源。

手机只访问当前仓库。通行码 5 分钟有效、仅使用一次，会话最长 12 小时；默认只读，读写权限由电脑生成本次通行码时决定。电脑可撤销全部会话或关闭入口，切换仓库和程序重启也会使旧会话失效。修改权限需重新生成通行码并在手机重新连接。

只读权限由服务端检查；设置、同步和仓库管理只允许电脑本机操作。内部目录不能通过附件或文件管理接口访问。连接仍使用普通局域网 HTTP，不提供链路加密，请仅在可信网络使用，不开放到公网。电脑关闭或离开同网后，当前不能继续浏览整库。

两套Tracery之间同步仓库时，在“设置 → 同步”由一端开启共享，另一端选择附近设备并输入六位配对码。mDNS负责发现，配对码负责授权；可使用旧UDP发现或手动地址回退。同步入口的随机端口和手机网页端口是不同入口。

已有NAS用户也可选择自托管同步服务，见[同步服务使用说明](sync-server/README.md)。笔记库同步、普通手机网页、PWA应用资源缓存与完整离线仓库是不同能力；手机目前没有完整独立离线库。PWA安装与使用见[移动版说明](docs/PWA.md)。

## 数据、备份与卸载

笔记是仓库目录中的Markdown文件，附件也在仓库内。关闭应用后复制整个仓库即可备份笔记与附件；恢复时打开复制后的文件夹。绘图场景文件及隐藏的`.tracery`目录也应保留。

Windows桌面设置和本机历史版本位于`%APPDATA%\\tracery`；如需完整迁移本机使用记录，也要备份此目录。源代码运行默认将设置保存在项目目录，可通过`TRACERY_HOME`指定单独位置。新历史按笔记独立身份保存，最多保留 20 份；旧版历史保留可预览，但来源无法验证时会标明并禁止直接恢复，可手动复制或另存。请勿只移动、编辑历史文件而丢弃来源元数据。

卸载时删除程序目录即可。删除设置目录会清掉本机配置与历史记录，不会删除另存于仓库目录的笔记。

## 常见问题

- 手机无法连接：先确认电脑本机地址可打开，再检查同网、访客网络隔离、VPN、网卡选择与电脑休眠。防火墙应允许应用在私有网络接收连接，不要关闭整台电脑防火墙。
- 端口冲突：当前源码的桌面程序重复启动会恢复已有窗口；若端口被其他服务占用，会显示启动错误。关闭占用程序，或源码运行时通过`PORT`更换端口后重启。手机使用界面显示的实际地址，不要填写`127.0.0.1`或同步端口。已发布的 v1.11.0 ZIP 尚不包含此启动更新。
- 仍看到旧界面或图标：关闭旧程序，从新解压目录启动；旧快捷方式可能仍指向旧目录。网页如提示有更新，先保存，再按提示更新。
- 保存失败：确认仓库仍存在、可写、磁盘空间足够；保留当前文字，排除故障后重试。不要仅以预览文字存在判断已经落盘。
- 加密同步口令不正确：使用同一测试副本核对口令和设置，勿用错误口令反复覆盖真实仓库；请妥善保存口令。
- 公式、复杂嵌套Markdown或其他软件的扩展语法可能存在兼容差异。当前不支持Obsidian插件API，也没有完整手机离线仓库。

源码使用者可运行`npm run test:smoke`或`npm run test:all`检查本机环境。自动测试使用隔离副本，报告保存在`dist/test-runs`；`npm run qa:prepare`可生成独立测试仓库和可填写的手工验收清单。实体手机、真实输入法与不同网络仍需现场测试。

浏览器测试可通过环境变量`TRACERY_BROWSER`指定 Chrome、Edge 或 Chromium 可执行文件的完整路径；此设置优先于套件原有路径。完整验收还包含真实 Electron 窗口的单实例、退出保存和端口占用检查，需要可启动桌面窗口的环境。

参与开发时先运行 `npm run check` 和 `npm run test:ci`；检查范围、CI 和 CSP 边界见[开发说明](docs/DEVELOPMENT.md)。这些源码更新尚未打包到 v1.11.0 ZIP。
