# Tracery v1.1.1

修复两个影响日常写作的编辑器问题，并完成编辑区内核迁移的 P0 / P1 阶段（内部工作，不影响现有用法）。

## 修复

### 1. 实时预览行号少一位（文末空行不编号）

**现象**：文件以空行结尾时（例如「段落 + 5 个换行」），Obsidian 的行号显示 1-6，Tracery 实时预览只显示到 1-5，最后一个空行没有编号。

**原因**：行号收集时跳过了「文末换行之后的那一行」——早期实现误以为 Obsidian 也不给末行编号。

**修复**：按 CM6 / Obsidian 的口径编号——**行数 = 换行数 + 1，文末空行也有行号**。GUI 实测同一文件两边完全一致（1-11）。

### 2. 行首连续 Backspace 导致「视图与模型分裂」（严重）

**现象**：光标放在某行开头连续按 Backspace，视觉上多行合并了，但——行号槽残留成点不动的死区、Ctrl+Z 提示无可撤销、切到源码模式发现内容其实完好无损。删除只发生在 DOM 层，没有写进底层数据。

**原因**：浏览器原生的跨块合并不经过序列化（序列化按旧的行偏移「补换行」，把被合并的结构原样重建），md 没有变化，于是跳过重渲染，DOM 就停在改坏的状态。

**修复（两层）**：
- 跨行删除全部改走模型层：行首 Backspace（合并到上一行，列表/引用/标题标记一并去掉）、行尾 Delete（把下一行并进来）、跨块选区删除（按源码范围删）、列表/标题内容起点 Backspace（去掉标记）
- 追加安全网：**md 没变但 DOM 结构变了**（结构签名对比）就强制重渲染，任何没拦住的浏览器原生块编辑最坏也只是「操作弹回」，不会再出现死区和状态分裂

## 内部改进（编辑区内核迁移 P0 / P1）

按既定的迁移方案（`docs/EDITOR-MIGRATION.md`）推进 Obsidian 同款行级内核（CodeMirror 6）：

- **P0 探针**（独立页面 `public/cmlab.html`）：中文输入法组词、行号、3000 行滚动、widget 高度变化滚动稳定性、撤销选区恢复——5 项全部实测通过。顺带取证了 Obsidian 的实时预览实现（主 bundle 在 `resources/obsidian.asar`，编辑器确认为 CM6，行号用原生 `lineNumbers()`，实时预览是 StateField 托管装饰集），结论写进迁移文档
- **P1 只读渲染**：`markdown.js` 拆出 `parseMarkdown`（块级 AST，行为不变的纯重构）+ 新增 `public/js/cm/decorations.js` 装饰生成器——标题层级、粗体/斜体/删除线/高亮/行内代码、双链/标签、列表、引用、代码块围栏收起、分割线、表格行，**与现有块级渲染共用同一份解析**；光标所在行显示原始语法标记（Obsidian 同款）
- 探针页新增第 ⑤ 项「装饰渲染」10 条断言，与块级渲染逐项对齐

现有编辑区（`editor.js`）的对外行为没有变化，以上是迁移准备，不是切换。
