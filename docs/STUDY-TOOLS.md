# PDF 摘录与全库任务

## PDF 摘录到笔记

1. 打开仓库内的 PDF，在内置阅读器中选中文字并复制。
2. 点击 PDF 文件栏的“摘录到笔记”。粘贴文字，填写 PDF 页码和目标笔记路径。
3. 点击“写入笔记”。目标不存在时创建，存在时追加到末尾；点击“打开目标笔记”查看。
4. 点击摘录下方的来源链接，回到这个 PDF 的指定页。

默认目标为 `论文摘录/<PDF 名称>.md`，也可选已有笔记或填写仓库内的 `.md`、`.markdown` 路径。每条摘录最多 32000 字符，按 Markdown 引用块保存，附带仓库相对路径和 `#page=页码`。文件名含空格、中文、`#` 或方括号时会编码保存路径；通过应用移动或改名 PDF、目录时，沿用附件引用更新机制，保留页码及链接显示文字。

**页码需要手动确认**，使用阅读器显示的物理页序号（从 1 开始），不是论文印刷页码。本版不自动读取选区、当前页或总页数，不提供 OCR 和 PDF 批注；扫描件需要另行转成文字。跳页使用内置阅读器的标准页码链接。

如果目标笔记被外部修改，写入会停止并保留摘录文字。先查看原笔记，再点击“重新核对目标”后写入。请求结果未确认时，应先核对目标；相同请求在版本校验下可识别刚才的成功写入，避免直接重复追加。

关闭摘录窗口会在本次应用会话暂存未写入文字、页码和目标；退出或刷新应用会丢失这份暂存，请及时写入。切换仓库后，原窗口只保留文字供复制，需要返回原仓库重新打开。只读授权不能写入摘录。

## 全库任务

从笔记库“更多”菜单选择“全库任务”，或在右侧信息页点击“全库任务”。命令面板也可搜索“全库任务汇总”和“摘录当前 PDF 到笔记”；快捷键设置中可分配按键。

任务使用普通 Markdown 列表语法，保存在原笔记中：

```markdown
- [ ] 阅读论文 due:2026-11-01
- [x] 完成课程笔记
1. [ ] 整理实验 📅 2026-11-03
- [ ] 复习线性代数 到期:2026-11-05
```

支持 `[ ]`、`[x]`、`[X]`，以及嵌套列表和引用中的列表任务。代码围栏、缩进代码示例和文件开头的属性区不计入任务；属性区损坏、缺少结束标记的笔记暂不列入，需先修复。任务正文以文字展示，不执行脚本。

可查看未完成、已到期、已完成或全部。未完成且到期日期为服务器本地今天或更早的事项属于“已到期”；未填或无效日期不算到期。日期须为有效的 `YYYY-MM-DD`，上述三种日期标记与前文用空格分开，行内代码中的日期不计。排序依次考虑完成状态、到期日期、来源路径和行号；每页 100 条。

搜索支持关键词、引号短语、`path:目录`、`tag:标签` 和减号排除，语法同高级搜索。关键词匹配任务文字或来源笔记名称；标签来自所属笔记。顶部数量按当前查询统计，再按显示范围筛选。

勾选或取消任务只改变原笔记对应复选框的一个字符，不重排正文、不自动添加完成日期。更新沿用历史版本和保存冲突检查；若原笔记变化，拒绝修改并刷新列表，请核对后重试。点击来源名称打开原笔记并定位任务行。只读授权可查看、筛选、打开来源，不能勾选。

任务列表是原文件的汇总视图，不另存一份任务数据库；笔记和任务仍随整库备份保存。外部文件变化会触发刷新，也可手动点击“刷新”。
