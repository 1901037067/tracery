# 文件整理、完整备份与恢复

本文描述当前源码提供的入口。

## 移动、改名与丢图

在文件树中右键文件或目录，选择“重命名”或“移动到…”。目标目录输入 `/` 表示仓库根目录。程序先保存当前笔记，再按实际解析到的文件更新引用；同名文件不会仅凭名字一起替换。支持双链、图片嵌入、普通 Markdown 链接/图片和引用定义，保留别名、图片宽度、锚点及链接标题，代码示例不改写。目录中的笔记移动后，其指向外部文件的相对路径也会调整。绘图图片的 `.draw.json` 数据会一起移动。

图片未找到时，点击“重新关联…”，选择仓库内的正确图片。当前笔记中匹配的缺失引用会更新，图片宽度等参数保留。不会自动删除已经误建的文件，也不会从外部位置擅自导入文件。

## 创建完整备份

打开“设置 → 通用 → 完整本地备份与恢复”，选择当前仓库之外的存放文件夹，点击“创建完整备份”。桌面版可用选择文件夹按钮；源码浏览器入口也可填写本机绝对路径。

备份包含当前笔记、仓库中的附件和绘图数据、空目录、当前仓库的版本历史与回收站，以及本浏览器的标签、阅读位置、分组、收藏和保存的工作区。界面设置会一起保存。同步凭据、索引缓存、开发内部目录及未保存草稿不进入备份。备份保存为普通文件夹，可以复制到移动硬盘；里面包含明文笔记与历史，应按自己的资料妥善保管。

文件复制后会回读核对大小与 SHA-256，最后提交清单。附件可超过旧历史导出的 32 MiB 限制；当前最多支持 20 万文件、20 万目录，校验清单最多 32 MiB，超限明确报错。该方式不是系统磁盘快照：备份期间仍可保存，但若源文件改变，本次备份会失败并提示重试。建议暂时停止其他设备写入，保持程序运行；退出会取消任务。失败或取消留下的 `.incomplete` 文件夹不能作为完成的备份恢复。

## 校验与恢复

选择已有完整备份后，“校验完整性”会独立检查清单和所有文件。选择恢复存放文件夹并点击“恢复到新仓库”，程序先校验，再生成新的仓库目录，不覆盖原仓库或备份。文件内容与修改时间保留，版本历史的仓库身份绑定到新位置；来源不确定的旧历史仍只提供预览。

完成后可点击“打开恢复的仓库”。勾选“应用备份的界面设置与工作区”时会恢复这些状态，包括这次明确操作要求打开的标签；随后普通启动仍遵守原先的启动偏好。同步连接需重新配置。若工作区存储空间不足会报错并回退本次状态写入；已恢复的文件夹仍保留。

内容校验可发现缺失或损坏，不证明备份来源可信；只恢复自己信任的备份。文件替换、进程中止和恢复测试不代表验证了所有硬盘的真实断电行为。
