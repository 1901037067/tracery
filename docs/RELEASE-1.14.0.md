# Tracery v1.14.0

这次更新补齐日常记录、笔记整理和论文阅读流程，并统一设置与备份界面的操作规则。

- 新增模板与快速记录：内置课程、论文、会议模板，支持标题、日期、时间和选区变量；自定义模板保存为普通 Markdown 文件。`Ctrl+Shift+N` 快速记录，按仓库保留本设备草稿，同名笔记不覆盖。
- 新增高级搜索与保存搜索：支持短语、目录、标签和排除条件组合；每个仓库可在本设备保存常用搜索，并随完整备份的工作区状态恢复。
- 新增笔记属性与列表：填写课程、状态、掌握程度、复习日期和标签，以 Markdown 文件开头的属性区保存；列表支持筛选、排序、分页及待复习检查。
- 新增 PDF 摘录到笔记：复制文字后确认物理页码，写入新笔记或追加到已有笔记，自动附带文件及页码来源；点击来源返回原页。通过应用移动或改名 PDF 后保留页码引用。
- 新增全库任务：汇总 Markdown 任务，筛选未完成、到期、完成事项，点击来源定位原文；勾选只改原笔记的复选框字符，并保留历史版本及冲突检查。
- 优化设置与备份恢复界面的密度、层级、状态反馈、菜单键盘操作和弹窗焦点；补充明暗主题及窄窗布局。
- 新写入流程核对笔记版本及仓库身份。外部修改冲突时保留输入并要求核对，不覆盖已有内容；只读授权可以查看列表，不能修改属性、任务或写入摘录。

使用入口：笔记库“更多”菜单、命令面板、右侧信息页；PDF 摘录位于已有 PDF 文件栏。

使用说明：[模板、搜索与属性](https://github.com/1901037067/tracery/blob/v1.14.0/docs/NOTE-TOOLS.md) · [PDF 摘录与任务](https://github.com/1901037067/tracery/blob/v1.14.0/docs/STUDY-TOOLS.md)。

PDF 摘录目前需要手动复制文字、确认阅读器中的物理页码，不含 OCR、自动获取选区或 PDF 批注。属性表单支持受限的 YAML 字段，不运行插件或查询脚本。

下载 Windows x64 ZIP，解压整个文件夹后运行 `Tracery.exe`，保留旁边的 DLL、`resources` 和许可文件。本次不修改已有笔记格式；重要笔记可先做完整备份。
