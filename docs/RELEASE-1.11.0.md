# Tracery v1.11.0

- 统一分组内、分组外及空白标签的选中样式：完整圆角卡片、细边框与强调线；分组名称和顶部色线继续保留组色。
- 文件列表以笔记为主：Markdown 和文本笔记不再显示重复的文件图标，PDF 显示独立类型标记。PPT、Word、Excel、CSV、压缩包等暂不支持查看的格式不再列出，原文件和同步保持不变。
- PDF 在主编辑区的标签页中打开，可从文件树、收藏或正文附件条进入，支持切换、关闭与刷新恢复；保存失败时不会绕过当前笔记的保存保护。
- 修复图片、附件条和嵌入笔记卡片之后的行号错位；调整引用卡片为中性浅底、细边框及紧凑标题栏。
- 修复绘图线型选中时虚线和点线看似实线的问题；工具栏在空间足够时保持一行，窄屏才换行。最小桌面窗口保留单行标题栏。
- 图标提示跟随主题，支持快捷键展示、键盘焦点和窗口边缘避让。
- 连接恢复后核对当前仓库并补查文件变化，修复断线期间更新后嵌入内容仍停留在旧版本的问题；保留未保存输入。

下载 Windows x64 ZIP，完整解压后运行 `Tracery.exe`。已有笔记库可直接打开，无需转换格式。工作区、分组和未保存草稿仍属于当前设备数据。
