# Tracery v1.15.0

这次更新集中改善主题、导航与 Markdown 阅读体验。

- 新增暖纸、青岚、暮蓝三款皮肤；原“Apple 风”更名为“清简”，保留原配置。五款皮肤均支持明暗模式，设置中可直接预览。
- 手机访问按访问状态、权限设置、使用说明分区；开启后集中显示通行码和地址，并保留会话撤销、关闭及读取失败重试。
- 笔记信息分为基本信息、标签和更多操作；长路径自动换行、可单独复制，标签汇总属性与正文，支持直接进入标签编辑。
- 调整底部仓库工具大小，与设置、分页按钮及编辑区分隔线对齐；笔记列表和全库任务使用导航侧栏固定入口。
- 收起导航侧栏后，悬停文件、搜索或标签图标可临时预览，移开自动隐藏；修复收起侧栏后文档标题区域被撑高的问题。
- 标签组增加展开、收起的箭头及数量提示；分组菜单使用方形色块、操作图标和分隔线。
- 文件夹去掉独立展开箭头，通过层级竖线提示目录结构；仍可点击文件夹或按 Enter、空格展开和收起，大仓库同样适用。
- 命令面板统一为单色线条图标，修复部分图标显示成源码的问题。
- 修复表头文字多余下划线，改善表格和正文样式，为编辑区增加柔和阴影。
- 文件树、最近打开和搜索结果默认在当前标签页打开文件；Ctrl/Command 点击、中键及右键菜单仍支持新标签页。保存失败时保留原标签及输入。
- 修复标准 Markdown 库内链接的实时预览和跳转，支持同级、父目录、中文文件名、空格和标题定位；保留链接原文与源码编辑方式。

下载 Windows x64 ZIP，解压整个文件夹后运行 `Tracery.exe`，保留旁边的 DLL、`resources` 和许可文件。关闭旧版后再启动新版，已有笔记、附件和主题配置继续使用。

手机访问仍需电脑与应用保持运行，并处于同一可信局域网；本次没有新增完整手机离线仓库。
