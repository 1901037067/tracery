# 手机使用与 PWA 安装

Tracery 的移动版连接现有仓库服务，笔记仍以该服务所在机器的 Markdown 文件为准。手机、平板和桌面浏览器访问同一个服务时使用同一个当前仓库。

服务可以直接运行在你自己的电脑里，不需要租云服务器或购买域名。点电脑应用左侧导航栏底部、主题与设置之间的手机图标，可查看并复制当前网卡与端口对应的访问地址。

## 打开与安装

1. 在电脑打开新版 Tracery 桌面程序和目标仓库，保持电脑 / 程序运行；桌面版自带本机服务。源码开发者也可单独运行 `npm start`，两种启动方式择一。
2. 手机访问该服务的地址。局域网中可用 `http://电脑的局域网地址:9520` 打开移动网页版；这里的目录路径属于服务所在机器。
3. 普通局域网 HTTP 网页不要求先配置 HTTPS，也不要求先安装 PWA。完整 PWA 安装与 service worker 能力需要安全上下文，当前代码也据此注册 SW；部分浏览器可添加网页快捷方式，不等于具备完整离线能力。
4. 若已有合适的安全访问入口，可使用浏览器的安装 / 分享菜单；普通手机网页使用不需要购买域名或部署公网网站。

`localhost` 与 `127.0.0.1` 可用于本机开发测试；手机上的 `localhost` 指手机自身，不指电脑。HTTPS / 本机开发地址的要求来自浏览器的安装规则：[MDN 安装条件](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。

## 移动端操作

- 900px 及以下默认铺开编辑区，顶部保留仓库名、标签页与两侧栏按钮。
- 左侧按钮打开文件 / 搜索 / 标签抽屉。选择笔记后自动回到编辑区；点遮罩可收起抽屉。
- 右侧按钮打开大纲 / 关联 / 信息抽屉，点大纲标题后回到笔记。
- 绘图的图片库、颜色与样式通过上方按钮展开，工具条可横向滚动。画布与图谱支持触屏指针操作，缩放也可用工具按钮。
- 设置在手机上使用横向分类栏；弹窗、输入框、触摸区域和安全区随小屏调整。视口高度随软键盘变化，浏览器缩放仍可用。
- 切回桌面宽度会恢复原有三栏和栏宽，不改写桌面的侧栏折叠记录。

## 断线时的内容

- 在支持 SW 的安全上下文首次在线访问后，service worker 缓存应用静态资源；断线重新启动时显示重连页。普通局域网 HTTP 地址不注册 SW，不能承诺该冷启动离线页。
- 当前已打开的笔记可以继续输入。未保存文字立即按「仓库 + 笔记路径」保存在此浏览器中，保存失败会保留未保存状态。
- 重新连接并打开对应笔记时，会询问是否恢复设备草稿；确认前不覆盖仓库内容。保存成功后，只清除与已保存内容一致的草稿。
- 仓库 API 与附件不进入 service worker 缓存，离线时不能切换浏览其他笔记，也不自动执行后台同步。浏览器数据被清除后，设备草稿也会消失。

## 更新

静态资源发生变化会生成新的缓存版本。新版准备好后，页面显示「保存并更新」；有未保存内容且保存失败时，不刷新页面。Electron 桌面壳不注册 service worker，以免桌面包被旧浏览器缓存遮住。

## 无法连接

先确认电脑本机能打开笔记，再检查手机和电脑是否同网、电脑是否休眠、地址是否选到了 VPN 或虚拟网卡。避开访客 Wi-Fi 和客户端隔离，并允许 Tracery 在 Windows 私有网络中接受连接。

手机网页当前可以读写和管理电脑笔记库，没有独立只读授权；请仅在可信局域网使用，不要直接开放公网。
