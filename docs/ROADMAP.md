# Tracery 路线图：对比 Obsidian 的优势、要解决的痛点、要加的功能

> 这份文档回答三个问题：我们凭什么跟 Obsidian 竞争？用户为什么痛点？接下来做什么？
> 结论先行：**不做"更好的 Obsidian"，做"开源的 Obsidian 兼容备选"**——自托管同步、免费商用、中文优先、轻量快速。
>
> **当前第一优先级（2026-10-18 起）**：编辑区内核从块级实时预览迁到**行级 CodeMirror 6**（用户明确要求对齐 Obsidian 的编辑手感）。计划与验收标准见 `docs/EDITOR-MIGRATION.md`，本文件里的功能清单排在其后。

## 1. 诚实的现状评估

Tracery 目前是一个 **3,400 行的学习复刻品**（Node 服务端 + 浏览器客户端 + Electron 外壳），核心编辑器/双链/反链/图谱已可用并通过 11 项 E2E。

| 维度 | Obsidian | Tracery（现状） |
|---|---|---|
| 功能广度 | 插件 2000+、Canvas、Bases、白板、幻灯片 | 核心笔记功能 |
| 成熟度 | 5 年迭代、百万用户 | 学习项目 |
| 生态 | 主题/插件/教程社区 | 无 |
| 体积/启动 | 225MB、启动数秒 | ~120MB（Electron 版）、启动 <2s |
| 价格 | 个人免费、**商用 $50/人/年**、**同步 $4/月** | MIT 完全免费 |

**结论：正面拼功能广度必输。差异化只能打 Obsidian 的"不方便"和"要花钱"。**

## 2. Obsidian 的真实痛点（按用户感知强度排序）

| # | 痛点 | 严重度 | Tracery 的解法 |
|---|---|---|---|
| 1 | **同步要花钱**：Obsidian Sync $4/月，服务端在海外，国内不稳定 | 💰💰💰 | **自托管同步**：同步服务端一起开源，数据在自己机器上 |
| 2 | **商用要授权**：公司使用需 $50/人/年，法务风险让团队不敢推广 | 💰💰💰 | MIT 协议，免费商用零摩擦 |
| 3 | **闭源黑盒**：不能审计代码，同步服务端行为不可见 | 💰💰 | 全链路开源，同步协议可审计 |
| 4 | **启动慢、大仓库卡**：Electron 25MB + 全量索引，几千篇后明显卡 | 💰💰 | 3,400 行轻量实现 + 增量索引（P1） |
| 5 | **移动端割裂**：同步要装 App + 付费订阅才能用 | 💰💰 | **PWA**：手机浏览器即用，可"添加到主屏幕" |
| 6 | **上手门槛**：2000 插件选择困难，新手懵逼 | 💰 | 功能内置不折腾 + 新手引导（P1） |
| 7 | **中文体验**：英文优先 UI，中文分词搜索弱 | 💰 | 中文优先 UI/文档 + bigram 分词 + 拼音搜索（P1） |
| 8 | **发布要花钱**：Publish $8/月才能把笔记发成网站 | 💰 | **静态站点导出**：一键生成可部署 HTML（P1） |

## 3. Tracery 的优势（对外传播的话术）

1. **开源免费（MIT）**——个人、公司、魔改，零成本零法务风险
2. **自托管同步**——同步服务端开源，数据主权 100% 在自己手里；国内直连不限速
3. **Web/PWA 跨端**——手机打开浏览器就能写笔记，不用装 App
4. **轻快**——核心 3,400 行，启动 <2 秒，老电脑能跑
5. **中文优先**——界面、文档、搜索分词、字体渲染都为中文优化
6. **完全兼容 Obsidian  vault**——纯 `.md` + `.obsidian` 目录，双向可迁移，随时能回去
7. **可审计可魔改**——程序员用户能自己改功能（这是开源对极客群体的核心吸引力）

## 4. 功能路线图

### P0 — 差异化立足点

- [x] **自托管同步 v1**（杀手级，已完成）
  独立 CLI 同步服务端（`npx tracery-sync`）+ 内容寻址 blob + 版本化清单；三方比对（local/remote/base），
  冲突永久保留副本、删除进回收站，自动同步可配间隔。
  设计文档 [SYNC.md](SYNC.md)。
  - [x] v2：diff3 三方文本合并 + 附件分块上传 / Range 断点续传
  - [x] v3：端到端加密（scrypt + AES-GCM，服务端只存密文；见 SYNC.md 第 10 节）
  - [x] v4：局域网直连（UDP 广播 + 六位通行码，免部署）
  - [ ] v4b：mDNS 精细化发现 / 多仓库支持（当前是 UDP 广播启发式）
- [x] **PWA + 响应式布局**（2026-10-20）
  manifest / 安装图标 / service worker 静态资源缓存、更新提示与离线重连页；移动抽屉、触屏图谱与绘图、
  小屏设置及设备草稿恢复。笔记读写连接当前仓库服务，完整离线仓库与后台同步留待后续。
  手机安装条件与操作见 [PWA.md](PWA.md)。
- [x] **主题即配置**（已完成，替代了原计划的 Obsidian 配置导入）
  `public/themes/*.css` 全套变量 + 设置面板可视化调色 + 一键导出主题 CSS。
  用户和 AI 都能安全改，改坏了 `git checkout` 还原——比硬导 `.obsidian/` 私有格式更实在。

### P1 — 体验打磨

- [x] **附件管理**：新附件落点三档可配（指定文件夹 / 跟随笔记 / 仓库根目录）+ 粘贴/拖拽图片文档自动入库插链（2026-10-17）
- [ ] **中文搜索增强**：bigram 分词 + 拼音首字母检索（输入 `shuanglian` 命中「双链」）
- [ ] **静态站点导出（数字花园）**：vault → 可部署 HTML（双链可点击 + 图谱页 + 客户端搜索），对标 Obsidian Publish 但免费自托管
- [x] **大仓库性能**（2026-10-20）：文件树虚拟滚动 + `.tracery/index.json` 增量复用；普通编辑只更新相关反链，
  隐藏图谱按需加载。一万篇实测与限制见 [PERFORMANCE.md](PERFORMANCE.md)。
- [ ] **更大规模优化**：图谱力导向算法、全文倒排索引与正文内存占用。
- [ ] **新手引导**：首次启动交互教学 + 常用模板（日记/MOC/读书笔记）
- [x] **回收站**：删除进 `.tracery/trash`，可恢复（2026-10-17）

### P2 — 生态（做大了再说）

- [ ] 插件 API + 沙箱（Web Worker 隔离，吸取 Obsidian 插件质量参差的教训）
- [ ] 主题系统（CSS 变量已就绪，差市场）
- [ ] 多人协作（同步服务端天然支持，加个 presence 广播）

## 5. 开源运营建议

1. **第一个 Release**：v0.1.0 + portable exe + "逆向 Obsidian 并开源复刻"的故事（REA 分析报告本身就是好内容，见 `docs/OBSIDIAN_ANALYSIS.md`）
2. **README 三件套**：一句话定位、GIF/截图、5 分钟跑起来
3. **CI**：push 自动跑 E2E（`.github/workflows/ci.yml`）
4. **传播渠道**：V2EX / 掘金 / 少数派发《我用 REA 逆向了 Obsidian，然后开源复刻了它》——逆向过程 + 架构对照表是最吸引人的部分
5. **社区**：开 Discussions，Issue 模板；先征集"你最想要 Obsidian 的哪个免费替代能力"，让路线图由需求驱动

## 6. 明确不做的事

- 不追求插件数量（质量 > 数量，内置 > 可装）
- 不做第二个同步付费服务（同步永远免费自托管）
- 不兼容 Obsidian 插件生态（API 完全不同，投入产出比太低）
