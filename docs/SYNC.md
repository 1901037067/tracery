# 同步指南

Tracery 可以只在一台电脑上离线使用，同步是可选功能，不要求购买服务器或域名。手机仅查看电脑当前笔记库时，使用 [手机网页访问](PWA.md)，无需先配置同步。

## 同一局域网内同步

两台运行 Tracery 的电脑可通过六位通行码配对。操作步骤和发现故障处理见 [附近设备](MDNS.md)。主机必须保持运行，首次合并前请备份两边笔记库。

## 使用自己的同步服务

若已有 NAS 或另一台常开电脑，可以选择 [安装同步服务端](../sync-server/README.md)。在客户端“设置 → 同步”填写服务地址、配对码和设备名称后连接。服务端地址与手机笔记网页地址不是同一个入口。

## 可选端到端加密

在同步设置中按提示开启加密，并在其他设备输入相同密码。服务端保存加密内容；本机笔记仍是普通 Markdown 文件。重启后需要按提示解锁。

请妥善保存密码。忘记密码后无法从加密的服务端数据恢复正文；服务端没有可帮你找回的明文密码。不要直接切换已有同步空间的加密方式，按界面提示处理，先保留完整本地备份。

## 冲突与中断

- 两端修改不同段落时，会尝试自动合并；不能自动合并时保留冲突副本，请打开对照后手动整理。
- 同步过程中断后，检查连接状态再重试；不要只凭另一台设备上的旧画面判断内容已经一致。
- 同步也会传播删除，不能代替备份。定期将整个笔记库和附件复制到独立存储。

## 连接失败

确认服务仍运行、地址和端口正确、网络互通以及配对码有效。HTTP 连接限可信网络使用；如需通过不可信网络连接自托管服务，请配置 HTTPS 或可信 VPN。

主应用手机网页当前没有独立登录或只读授权，不应直接开放公网。通行码保护的同步服务与主应用网页是不同接口。
