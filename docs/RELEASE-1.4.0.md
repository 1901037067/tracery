# Tracery v1.4.0

这一版是**内部减法**：下线旧的块级编辑内核，编辑器只保留 CodeMirror 6。
功能没有减少，但渲染相关的 bug 少了一整套来源，代码也轻了 1300 多行。

## 变化

### 1. 编辑器只保留 CodeMirror 6（Obsidian 同源的行级内核）

之前编辑器有两套实现：新的 CM6（行级真实文本 + 装饰）和旧的块级内核
（把整篇 Markdown 重建为 DOM）。两套并行维护的代价是——**每个渲染类改动都要写两遍、测两遍**，
而「整篇重建」正是光标跳动、空行错位、图片宽度失效、表格列错乱这些问题的根源。

所以这一版把旧内核整体删除：

- 设置 → 编辑器 里不再有「编辑内核」开关，默认（也是唯一）就是 CM6；
- 旧内核的代码（`public/js/editor.js`，1310 行）、样式与测试口径一并移除；
- 用过旧内核的用户升级后会自动使用 CM6，笔记与设置不受影响。

### 2. 测试收敛到单一内核

15 个回归套件去掉双引擎参数化，只跑一套断言；`TRACERY_TEST_ENGINE` 环境变量不再生效
（仍可传入，不会报错）。

## 验证

- 15 个界面/功能套件全绿：e2e 15、ui-ux 16、tabs 16、draw 37、features、
  layout、polish、gap、menu、asset、trash、roundtrip、enter、backspace、ui-vault
- 同步：`test:sync` 27/27、`test:sync-enc` 20/20
- 打包版 `node test/verify-exe.mjs` 14/14

## 升级

替换 exe / 解压覆盖即可。仓库、设置、同步配置都不受影响。
如果你之前把内核切到过「块级」，升级后会使用 CM6——这是预期行为。

想回到双内核版本：`git checkout v1.3.0`。
