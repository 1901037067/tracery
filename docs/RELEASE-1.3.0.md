# Tracery v1.3.0

这一版把编辑体验和同步安全都往前推了一步：**标签栏无缝化**、**cm 表格能直接编辑**、
**绘图支持二次编辑**，以及**同步 v3 端到端加密**（服务端只存密文）。

## 主要变化

### 1. 同步 v3：端到端加密（可选，配对时开启）

开启后，同步服务端（NAS / 树莓派）**只看到密文和哈希后的文件名**：

- 密码只在本机派生密钥（scrypt → HKDF 分出内容密钥 / 路径密钥），**不上传、不落盘**；
- 文件内容 AES-256-GCM 加密；manifest 里的路径换成 HMAC，服务端无法反推文件名；
- 换设备输同一个密码即可解密；重装后用「解锁」把钥匙装回来；
- 合并、冲突副本、分块上传、断点续传全部照常工作（引擎在设备端解密后再合并）。

⚠️ 密码忘了，云端数据就无法恢复——服务端既没有明文也没有密码。

### 2. 绘图支持二次编辑

图片右键 → 「编辑绘图」：载入保存时的场景（`.draw.json`），改完保存**覆盖原图**，
笔记里的引用不用动，也不会多出一张新图。

### 3. cm 表格单元格编辑

表格在实时预览里是一个真正的网格（管道字符隐藏、列宽按内容实测）：

- 点进任意单元格直接改；
- `Tab` / `Shift+Tab` 在单元格之间跳（末行末格 Tab = 自动加一行）；
- `Enter` 加一行同样列数的空行；
- 表格比正文宽时整行横向滚动，不会把单元格挤到下一行。

### 4. 标签栏无缝

标签之间不再有缝隙：整条标签栏只在两端圆角，中间用 1px 分隔线；
活跃标签用强调色文字 + 底部 2px 强调线；悬停只换文字色。
标签仍可**拖拽换序**（活跃标签跟着那篇笔记走）。

### 5. 工作区下拉

点左上角工作区名先弹出**最近仓库列表**（当前仓库带 ✓），最后一项才是「管理仓库…」，
不再直接跳转到仓库管理页。

## 修复

- 表格里较长的数字/中文会整格折行、列对不齐（现在按真实字体测量列宽，并禁止单元格内折行）
- 图片右键菜单新增「编辑绘图」，覆盖保存后正文里的图片会立即刷新（不走旧缓存）

## 下载

Gitee 发行版的**单个附件上限是 100MB**，本项目的 zip 约 110MB 会被拒收（网页上会报
"Something went really wrong, and we can't process that file"）。所以这版提供两种包：

- **推荐：`Tracery-1.3.0-win32-x64.7z`（约 71MB）**
  Windows 11（23H2 起）双击即可解压；Windows 10 需要装 7-Zip / WinRAR / Bandizip。
- 备选：`Tracery-1.3.0-win32-x64.zip.part1` + `.part2`（各约 55MB）
  两个文件下到**同一个目录**，在该目录打开命令提示符执行：

  ```
  copy /b Tracery-1.3.0-win32-x64.zip.part1 + Tracery-1.3.0-win32-x64.zip.part2 Tracery-1.3.0-win32-x64.zip
  ```

  合并后的 zip 与官方包逐字节一致（默认解压即可）。

## 升级

替换 exe / 解压覆盖即可，**仓库与设置不受影响**。
已连接的同步不会自动变成加密——需要加密时请断开后重新配对，并在配对时勾选「启用端到端加密」
（已有明文数据的仓库不能直接开加密）。
