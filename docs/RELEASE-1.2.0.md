# Tracery v1.2.0

**编辑内核换成 Obsidian 同款的行级引擎（CodeMirror 6）**，并补齐配套样式与全量双内核回归；另修两个日常写作会碰到的问题。

## 主要变化

### 1. 编辑内核：块级实时预览 → 行级 CodeMirror 6（已切为默认）

- 实时预览改由 CM6 的行级模型渲染：标题层级、粗/斜/删/高亮/行内代码、双链/标签、列表、引用、
  代码块围栏收起、分割线、表格；**光标所在行显示原始语法标记**（Obsidian 同款）。
- 撤销/重做交给 CM6 的 history：连续输入合并成一步、结构操作单独成步、撤销后能重做
  （`Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y`），并会还原选区与滚动位置。
- 回车续列表 / 任务列表、Tab 缩进、`Ctrl+B/I/S/K`、粘贴与拖入附件落盘回插 `![[路径]]`、图片拖宽、
  复选框、Callout、表格行装饰、`![[笔记]]` 嵌入卡片、行号（设置里可关）全部在 cm 内核下可用。
- 旧的块级内核**没有删除**：设置 → 编辑器 里的内核开关可一键回退，URL 加 `?engine=block|cm`
  也能按页覆盖（便于对比与排查）。

### 2. CM 内核的样式补全（明暗主题跟随）

新增 `public/css/cm.css`：标题字号/行内样式/引用与 Callout 底色/表格边框/图片框与拖宽手柄/
复选框/行号槽外观全部对齐块级渲染的视觉；**颜色一律用主题 CSS 变量**，apple/obsidian × 亮暗
自动跟随。同时收敛了编辑区的双滚动条（cm 下滚动交给内部 `.cm-scroller`）。

### 3. 测试与打包

- 回归套件全部支持双内核口径（默认跑块级作回归网，`TRACERY_TEST_ENGINE=cm` 跑 cm 口径），
  本轮 **block 22 套件 / cm 16 套件各跑一遍全绿**；CM6 探针页 8 项 + 中文输入法组词全过。
- 打包版验证 14/14；`npm run dist:dir:nosign` 是本机（无符号链接权限 + 连不上 GitHub）的出包入口。

## 修复

1. **CRLF 换行的笔记「大纲」是空的**（Windows 上 git 检出成 CRLF 的笔记全部中招）：逐行扫标题的正则
   里 JS 的 `.` 不匹配 `\r`、`$` 也不落在 `\r` 之前，导致一条标题都扫不到，右栏显示「当前笔记没有标题」。
   已改为扫之前统一归一化换行。
2. **cm 内核粘贴的图片不改名**：截图/复制的 `image.png` 会原样落盘（连粘两张互相覆盖），
   现在与块级一致改为 `粘贴的图片 <时间戳>.png`。
3. **cm 内核下三处手感问题**：空列表项/空引用回车不退出列表（现在能退出）；在选中的文字上右键会把
   选区收拢成光标（现在保住选区，「加粗/斜体」不再落空）；隐藏语法标记会把标题行撑高 23px
   （光标进出标题时整篇跳一下，现已压平）。

## 升级

替换 exe / 解压覆盖即可，**仓库与设置不受影响**。若想回到旧的块级编辑体验：设置 → 编辑器 → 内核。

## 已知限制（cm 内核，计划下一版补）

- 行内 `![[图片]]`（前面有文字的那种）与 `![](路径)` 的 Markdown 图片**暂时不渲染成图片**，
  只显示文字标记；只有「整行就是一个 `![[..]]`」才会出图。
- 未解析的双链暂时没有「灰色虚线」样式（块级内核有）。

## 本版打包说明

本机既没有创建符号链接的特权、又连不上 GitHub（winCodeSign 缓存下载超时），因此包用
`npm run dist:dir:nosign` 产出：**功能与完整包完全一致**，仅 `Tracery.exe` 文件本身没有自定义图标/
版本信息（窗口与任务栏图标正常）。
