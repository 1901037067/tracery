# Tracery v1.10.0

- 布局预设升级为工作区：按笔记库保存打开的笔记、活动标签、分组和颜色、侧栏布局与页签、阅读模式和位置。顶部标签菜单一键切换；支持 JSON 导入导出和旧布局预设迁移。
- 固定侧栏导航图标行，文档库、星标、最近打开和分组之间切换时保持对齐；文档库操作按钮与分割线在独立下方区域。
- 绘图工具条展示完整工具，窄屏自动换行；设置导航增加统一图标，下拉菜单适配主题并支持键盘操作。移除标题栏重复的布局入口。
- 拖动标签或分组时展示让位动画、插入线和松手后的排列预览。
- 改进长期使用与故障恢复：安全写入和版本冲突检查，保存失败保留输入并阻止切换、退出；恢复中心可预览、导出或另存草稿。修复 UTF-8 分段读取和异步旧响应覆盖问题。

下载 Windows x64 ZIP，解压后运行 `Tracery.exe`。已有笔记库可直接打开，无需转换格式。工作区和未保存草稿属于当前设备数据；工作区导出不包含笔记正文，不能替代笔记库备份。
