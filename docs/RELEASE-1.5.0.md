# Tracery v1.5.0

本地 Markdown 笔记软件，无需云账户、付费服务器或域名。此版本更新了侧栏、快捷键、应用图标和入门笔记，并改善编辑与同网访问体验。

## 下载与运行

下载下方的 `Tracery-1.5.0-win32-x64.zip`，解压整个文件夹，双击 `Tracery.exe`。适用于 Windows 10/11 64 位，不需要另装 Node.js。请保留旁边的 resources 和 DLL 文件，不要只复制一个 exe。

`SHA256SUMS.txt` 用于校验下载文件。GitHub 自动生成的 Source code 是源码，不是桌面应用包。

## 新增与改进

- **侧栏更简洁**：左栏叠页、星星、时钟分别切换笔记库、收藏和最近打开；右栏按需切换大纲、关联和信息。
- **快捷键可修改**：设置 → 快捷键，可搜索命令、录制新组合、查看冲突、清除或恢复默认。修改后立即生效，重启保留。
- **新的应用图标**：桌面程序、网页与主屏幕图标统一更新。
- **手机访问入口**：左侧底部主题和设置之间的手机图标显示当前电脑的局域网访问地址。
- **同网同步发现**：设置 → 同步，可选择附近正在共享的设备，再输入通行码配对；找不到时仍可填写手动地址。
- **移动网页与大笔记库**：改善小屏抽屉、触屏操作、断线草稿保护及大文件树浏览和索引加载体验。
- **更清晰的示例库**：保留五篇入门笔记和附件，更新操作说明与链接，移除旧的片段、日记、项目和 Markdown 语法笔记。

## 修复

- 标题、提示块附近点击正文时，光标可能落到错误行。
- 窗口很宽时，行号与正文距离过远。
- 标签栏右上角下拉菜单再次点击不能收起。
- 笔记库下方空白区域右键不显示菜单。
- 更新示例库后，桌面程序首次复制示例的判断仍依赖已移除的文件。

## 手机访问的范围

手机与电脑连接同一可信局域网，电脑保持运行 Tracery 且不休眠，再用手机浏览器打开应用显示的地址。网页可以读写电脑当前笔记库，目前没有独立只读授权，请勿直接开放公网。

普通手机网页访问不要求安装 PWA。完整 PWA 安装受浏览器安全上下文限制；当前不提供完整手机离线笔记库，电脑关闭或离开同网后不能继续浏览整库。附近设备发现用于同步配对，与手机网页入口不同。

## 从旧版升级

先备份自己的笔记库和附件，退出旧程序，把新包解压到独立目录再运行。已有个人笔记库不需要迁移；此版本不会删除旧笔记库中的日记、项目或其他个人文件。旧版已经复制到本机的示例内容也不会被自动清理。

默认 `Ctrl+S` 是删除线；笔记会自动保存。需要“立即保存”快捷键时，请在设置中自行绑定。

安装、备份与排障见 [使用说明](https://github.com/1901037067/tracery#readme)。
