# 同网设备发现与配对

附近设备列表用于两套 Tracery 之间同步笔记库；手机浏览器查看电脑笔记，请使用左侧底部的手机图标，见 [手机访问说明](PWA.md)。

## 连接

1. 两台电脑连接同一可信局域网，分别打开要同步的笔记库。首次同步前各自备份整个笔记库。
2. 主机在“设置 → 同步”点击“本机当主机，生成通行码”，保持程序运行。
3. 另一台电脑在“附近的共享设备”选择目标，输入主机显示的六位码，点击“连接所选设备”。
4. 首次同步会合并两边文件，不会只用一边覆盖另一边。发现同名冲突副本时，请对照内容确认后再整理。

只共享当前笔记库。停止共享、断开同步或切换笔记库会停止本次共享；一个实例不能同时共享多个笔记库。

## 找不到设备

- 点击刷新，检查主机是否仍在共享、电脑是否休眠。
- 避开访客 Wi-Fi、客户端隔离、VPN 和互不连通的网段；允许 Tracery 在 Windows 私有网络中接受连接。
- 自动发现使用 mDNS，旧版按码查找仍可兼容。网络禁止自动发现时，填写主机显示的手动地址。
- 同名设备请结合笔记库名和地址确认目标；设备名称本身不是身份认证。

发现设备、输入通行码和传输笔记是不同步骤。手机浏览器不能直接扫描 mDNS 来解决第一次找电脑地址的问题；PWA 安装也不会产生完整的手机离线笔记库。

更多同步与加密用法见 [同步指南](SYNC.md)。
