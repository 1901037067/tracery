# Tracery v1.4.1

- 增加阅读模式，可通过 Ctrl+E 切换三种模式。
- 标签栏右侧下拉可切换、关闭或收藏已打开的笔记。
- 改进列表标记、编辑区边缘和带 BOM 文件的标题显示。
- 补全双链点击、文件夹右键操作、绘图旋转与本机绘图草稿。

## 下载与升级

从 [GitHub Releases](https://github.com/1901037067/tracery/releases) 选择对应版本。升级前备份笔记库，退出旧程序后解压完整新包并运行。保留资源文件，不要只复制 exe。

这是该版本的历史变化；当前使用方法和限制以 [使用说明](../README.md) 为准。
