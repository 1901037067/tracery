# Tracery v1.4.1

这一版是**顺手修一堆日常硌脚的地方**：编辑器多了「阅读模式」，标签栏多了下拉菜单，
列表终于渲染成圆点而不是源码的横线，还有几条点不动 / 找不到的路径都通了。

## 变化

### 1. 阅读模式（编辑器第三种模式）

状态栏右下角的模式按钮（`Ctrl+E`）现在是三态循环：**实时预览 → 源码 → 阅读**。

阅读模式下笔记是**只读**的：没有光标、不能打字、不显示行号，所有 Markdown 标记一律隐藏、
图片/表格/复选框按成品渲染——就是「剥掉源码之后的样子」。但该点的还能点：
**双链和标签可以点击跳转/搜索**，**任务复选框可以直接勾选**，图片点一下看大图。

在阅读视图里点双链跳到别的笔记，仍然停在阅读模式（不会跳回预览）。

### 2. 标签栏右侧的标签页下拉

标签条最右边多了一个下拉箭头，点开是：

- **当前打开了哪些标签页**（当前那个带 ✓，点一项直接切过去，悬停看完整路径）
- **关闭所有标签页**
- **收藏所有标签页**：把打开的每篇笔记都加进文件树顶部的「星标」

### 3. 编辑区看起来「浮」在页面上

编辑区四周的缝隙以前是窗口底色（比侧栏暗一档），现在**刷成和左右侧栏同色**——
视觉上编辑区就是一张浮在侧栏底色页面上的纸。明暗主题都跟着走。

顺带把左侧栏的拖拽分隔条挪到了**纸张边缘**上（以前在侧栏和纸张之间），
拖拽位置和视觉边界现在是同一条线。

### 4. 列表标记渲染成圆点

- 无序列表：`-` / `*` / `+` 渲染成圆点 `•`（不再露出源码的横线），嵌套缩进不变
- 任务列表：去掉列表标记，只留复选框
- 有序列表：保留真实编号（`1.` `2.`）

顺带做了一次全量体检：`#` 标题、`>` 引用、粗体/斜体/删除线/高亮、行内代码、表格、代码围栏、
分割线、任务框、双链——全部都正确隐藏或渲染，只有列表标记这一处漏了。

### 5. 修复：首行带 UTF-8 BOM 的笔记，标题不生效

用记事本「UTF-8 带 BOM」另存的笔记，首行 `# 标题` 以前会被当成普通文本：
`#` 不隐藏、没有标题样式、右栏大纲也查不到。现在按正常标题渲染，大纲、标签、反链索引也都正常。

### 6. 修复：其它点不动的路径

- **编辑区双链/标签用鼠标点没反应**（以前只有键盘能跳）：根因是按下鼠标那一下会把光标落到该行，
  让渲染态的链接当场消失；现在鼠标点击照常跳转。
- **右键文件夹没有删除**：补齐了 删除 / 重命名 / 复制相对路径 / 在系统资源管理器中显示。
  删文件夹会**整棵目录一起进回收站**，可以整体恢复。
- **绘图无法旋转**：选中图形后顶边出现旋转柄，点住拖动即可旋转（按住 `Shift` 吸附 15°）。
- **绘图加了草稿箱**：可以随时「暂存」当前画板，之后从草稿箱重开继续画，也能同时保留多块画板
  （草稿只存在本机，不进仓库、不同步）。

## 升级

替换 exe / 解压覆盖即可。仓库、设置、同步配置都不受影响。

`Ctrl+E` 的行为变了：以前按两次是「源码再切回预览」，现在按两次会停在**阅读模式**（再按一次回预览）。
