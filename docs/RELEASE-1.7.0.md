# Tracery v1.7.0

## 新增与改进

- 绘图描边和图形背景新增选色板与十六进制色号输入，最近 8 个颜色保存在本机；原始预设色保留为紧凑色块。
- 完善笔记嵌入：输入 `![[` 可自动补全笔记、标题和文本块，支持完整正文、章节、文本块及别名，点击卡片箭头打开原文。
- 嵌入支持原笔记中的相对图片和双链，缺失引用会显示提示，原文件更新后刷新预览。嵌套笔记引用显示为链接，不递归展开。
- 顶部标签之间及标签列表剩余空白均可拖动窗口，标签与下拉按钮保持可点击。
- 绘图导航正确高亮；画板增加圆角和悬浮间距，工具栏上移并可拖动，支持点阵、网格线及空白背景；图片库分类按钮居中。

## 下载与使用

下载 `Tracery-1.7.0-win32-x64.zip` 并完整解压，运行其中的 `Tracery.exe`。无需安装 Node 或 Electron，请保留同目录下的资源与 DLL。校验文件见 `SHA256SUMS.txt`。

笔记和附件保存在自己的电脑里；升级前可备份整个仓库。手机访问需要同一可信局域网且电脑保持运行。更多操作见 [使用说明](https://github.com/1901037067/tracery#readme)。
