# Tracery v1.2.1

把 cm 内核与块级内核的**图片渲染断层补齐**，并顺手打磨两处编辑区视觉（图片交互、滚动条位置）。

## 新增 / 修复

### 1. cm 实时预览：行内图片与 Markdown 图片都能出图

v1.2.0 切到 cm 内核后，只有「整行就是一个 `![[..]]`」会渲染成图片：

- **行内 `![[图片]]`**（前面有文字那种）只显示一个文字标记；
- **`![](路径)` 的 Markdown 图片**完全不渲染。

现在两种都由行内 widget 渲染：出图、支持 `![[图|400]]` 宽度、右下角拖宽手柄、点图进灯箱；
代码块里的同名文本不会被误渲染。

### 2. 未解析双链的「灰色虚线」样式（cm 内核）

cm 下 `[[不存在的笔记]]` 之前和正常链接一个颜色。现在与块级一致：灰字 + 虚线底边
（颜色取主题的 `--link-unresolved`，明暗主题都跟随）。

### 3. 图片交互：虚线框与拖宽手柄改为「悬停才出现」

之前图片外面**常驻**一圈虚线框 + 右下角一个常驻的橘色方块，正文里非常吵。
现在：

- 默认只显示图片本身（圆角 + 阴影）；
- 鼠标移上去才出现**虚线框**（用 `outline` 实现，不改变盒尺寸、不会让行内图片一 hover 就重排）；
- 拖宽手柄平时完全透明、不挡事件，悬停时浮现，外观与块级内核统一（纸色小方块 + 发丝描边 + 右下折线）。

### 4. 滚动条贴着编辑区右缘

cm 内核的 `.cm-editor` 之前被「正文列宽 720px 居中」的规则限制，而滚动条属于它内部的
`.cm-scroller` —— 窗口一宽，滚动条就停在纸张中间（截图反馈）。现在：

- `.cm-editor` 撑满编辑区，滚动条贴右缘；
- 正文列宽改由 `.cm-content` 的左右 padding 居中（列宽设置 `--editor-width` 依旧生效）；
- 块级内核与源码模式同步去掉右侧那 8px 内缩，滚动条同样贴边。

## 内部

- 装饰的重建条件补上「索引版本」：笔记名索引 / 文件树刷新后显式 `refreshDecorations()`
  —— 修掉「笔记开得太早，`[[双链]]` 一直停在未解析」「刚粘贴的附件不出图」。
- 修 `![[..]]` 行内标记的吃字问题（开闭标记 3/2 不对称，之前把名字首尾各多吃一个字）。
- `setEmbedWidth` 改为按 token 起点原地改写（行内图片写宽度不再吞掉前后文字）。
- 行内图片加载完成后请 CM 重新测量（否则行号槽会停在图片尚未加载时的位置）。

## 验证

- 15 个回归套件在 **block / cm 双引擎**各跑一遍全绿；`test:engine` 12/12、`test:cmlab` 8 探针 + IME 全绿
- 打包版 `node test/verify-exe.mjs` 通过

## 升级

替换 exe / 解压覆盖即可，**仓库与设置不受影响**。若想回到旧的块级编辑体验：设置 → 编辑器 → 内核。
