# Tracery v1.4.2

这一版两件事：把「指向不存在笔记的双链」补完整，另外把 v1.4.0 下线块级内核之后留下的尾巴清干净。
没有界面改版，笔记文件格式与仓库结构都不变。

## 变化

### 1. 指向不存在笔记的双链：可以当场创建

以前写 `[[还没写的笔记]]`，预览里是一段普通文字，点了没反应。现在：

- 目标笔记不存在时，双链显示为**灰色 + 虚线下划线**，和已经存在的双链一眼分得开
- **点它一下**会问「创建「还没写的笔记」？」，确认后当场建好这篇空笔记并打开
- 右侧栏反链面板里的「未创建的链接」也是同一个入口，点一下同样能创建
- 和 Obsidian 一致：只在真正点的时候才创建，光标划过、切到源码模式都不会凭空多出文件

### 2. 块级内核遗留清理（无功能变化）

v1.4.0 已经把编辑器收敛到 CodeMirror 6 一套内核，这一版把剩下的残骸清掉：

- 删除 `app.js` 里只对旧块级 DOM 生效的处理器与光标定位辅助函数
- 删除 `style.css` 里 `.md-blank` 等死样式、`index.html` 里 `#editor-source` 等死节点
- 删除测试套件里的双内核分支（`IS_CM` / `ENGINE` / `?engine=`），所有断言只跑 CM6
- `docs/` 里的块级决策记录作为历史保留，不再参与运行

对使用者的影响：无。只是代码里不再有「另一套内核」的岔路。
