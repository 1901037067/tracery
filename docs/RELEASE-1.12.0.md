# Tracery v1.12.0

此版本更新本地访问保护、保存可靠性、界面与历史备份。

- 顶部左侧改为侧栏开关与工作区入口；活动标签使用更短的色条，组内沿用分组颜色。分组展开、收起有过渡动画，支持快速反向操作和系统减少动态效果。
- 两侧栏与导航栏使用轻微不同的底色；编辑区上方显示当前文档路径；图片和 PDF 在文件名右侧标注类型。
- 普通文件、图片与文件夹删除直接移入回收站；彻底删除与清空回收站仍需确认。
- 设置 → 通用新增历史备份导出、导入。跨位置导入需确认，只关联路径和当前正文均匹配的笔记；不修改原笔记、不覆盖已有历史，旧版来源不明的历史仍只供预览。
- 桌面默认仅监听本机。手机访问需在电脑显式开启独立入口，以通行码授权只读或读写；关闭、撤销与切换仓库会使会话失效。仍仅适合可信局域网，不提供 HTTP 链路加密或手机整库离线副本。
- 加强内部文件、配置、附件脚本和历史来源保护；改进搜索排序、代码围栏选择、单实例启动和安全保存后的外部修改监听。
- 仓库缓存改为按规模分片，减少普通编辑时的整库写入；暖启动继续复用正文缓存。缓存升级首次打开需要重建，启动耗时可能略有增加。

下载 Windows 64 位 ZIP，完整解压后运行 `Tracery.exe`。请保留旁边的 resources 与 DLL 文件。更新前退出旧版，使用新的解压目录；笔记文件夹保持原位置。

历史备份包含旧正文，需妥善保存。它不包含当前笔记和附件，不能替代仓库备份；界面支持 32 MiB 以内的历史备份，更大的历史请关闭应用后备份用户数据目录中的 history-v2 与 history 文件夹。切换电脑或移动仓库并不会自动找回未备份的历史。
