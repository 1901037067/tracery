# Tracery v1.13.0

这次更新完善文件整理与完整本地备份，修复图片引用和桌面布局，并加强异常退出与文件恢复。

- 文件或目录右键支持移动、改名，同时更新解析到该目标的笔记引用；保留链接别名、图片宽度与标题。图片的绘图数据一起移动，失败会尝试回退。
- 丢失图片增加“重新关联…”入口。图片、PDF 等附件不再列入待创建笔记，也不会误建为 `.png.md`。
- 设置 → 通用新增完整备份、独立校验和恢复到新仓库，包含当前正文、附件、绘图、空目录、历史、回收站及工作区设置。恢复保留原仓库和备份，可选择应用备份的界面设置与工作区。
- 完整备份逐文件回读校验，支持进度和取消；源文件变化时拒绝提交未完成备份。同步凭据、缓存和未保存草稿不包含在内。使用说明见 [完整备份与恢复](BACKUP.md)。
- 修复多文件移动中途失败的回退；跨盘回收增加刷盘、内容校验及源目录变化检查，异常时保留原件。
- 配置损坏可尝试上一份有效副本，回收站索引失败仍能找回项目；桌面启动显示进度并可取消，退出等待已接受的写入收尾。
- 编辑区外围缝隙与侧栏统一配色，短标签按内容收缩，文档分割线和顶栏控件对齐；PDF 移除重复标题行。
- 补齐离线编辑器依赖的许可证，Windows 包附带可直接阅读的第三方许可文件。

下载 Windows x64 ZIP，解压整个文件夹后运行 `Tracery.exe`。保留随包 DLL、`resources` 和许可文件；可以先用仓库副本体验移动与恢复。

本地全量回归首轮 61/65，修正测试夹具、等待条件及旧界面要求断言后，65 项均有最终通过记录。真实断电、实体手机和 macOS/Linux 原生桌面不在本次验收范围。
