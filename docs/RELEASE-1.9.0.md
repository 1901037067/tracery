# Tracery v1.9.0

侧栏布局现在可以按自己的习惯安排，并加强了文件接口的边界和请求来源校验。

- 文档库、星标、最近、分组、大纲、关联、信息统一为图标页签，支持跨左右栏拖动与前后排序；也可右键、使用键盘或在设置中调整。大纲使用圆点横线图标，关联使用双向箭头。
- 布局设置支持区域显隐、整栏换位、宽度与正文排版、命名预设及 JSON 导入导出；标题栏保留恢复入口。手机继续使用抽屉，文件入口会跟随文档库位置。
- 左侧新增命令按钮；顶部标签分组可以保存名称、颜色和笔记，在侧栏查看与整组恢复。
- 调整标签与组名对齐，移除活动标签顶部组色色边；保存分组卡片使用右上角色点。
- 文件写入、读取、创建、重命名、删除、历史恢复与附件接口统一检查路径边界，拒绝通过目录链接越出仓库；修复根目录保存同名附件的问题。
- 主服务校验 Host、浏览器来源与 JSON 写入类型，拒绝跨源 WebSocket；其他电脑/手机不能通过页面接口切换到服务器上的任意目录。
- 改善断线期间的后台刷新：保留已有侧栏内容，避免网络失败产生未处理错误。

下载 Windows ZIP，解压到新目录运行 `Tracery.exe`。笔记继续保留在原仓库，本机设置与历史记录继续沿用；压缩包旁附 SHA256 校验文件。

手机仍需与电脑同网，且电脑和 Tracery 保持运行。主服务没有独立账户登录，请仅在可信局域网使用；这次更新不包含完整手机离线仓库或 Obsidian 插件兼容层。
