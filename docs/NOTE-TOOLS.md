# 模板、搜索与笔记属性

从笔记库“更多”菜单进入“从模板新建”“快速记录”“笔记列表”。命令面板也可直接搜索这些名称，以及“编辑当前笔记属性”。

## 模板与快速记录

内置空白、课程、论文和会议模板。选择模板，填写笔记名称和仓库内的相对文件夹后创建；同名文件会提示冲突，不会覆盖。创建前可展开预览。

展开“编辑模板”可修改正文、另存为模板。自定义模板是 `模板/` 下的普通 `.md` 文件，可直接在文件树中编辑，也可在模板窗口保存修改。窗口最多列出前 200 份自定义模板。外部修改导致版本冲突时，编辑内容会保留，需重新核对后保存。

| 变量 | 内容 |
|---|---|
| `{{title}}` | 新笔记标题，不含 `.md` |
| `{{date}}` | 本地日期，如 `2026-10-29` |
| `{{time}}` | 本地时间，如 `09:05` |
| `{{datetime}}` | 本地日期和时间 |
| `{{selection}}` | 打开模板窗口时，当前编辑器中选中的文字 |

变量只替换一次，不执行脚本；未识别的变量保留原样。可“插入当前笔记”替换打开窗口时的选区；笔记或插入位置已变化时会要求重新打开。阅读模式和只读会话不可插入。

快速记录默认保存到 `收集箱/`，也可更改位置。桌面快捷键为 `Ctrl+Shift+N`，可在快捷键设置中修改。关闭窗口前，名称、文件夹和记录内容会暂存在此设备、当前仓库的浏览器存储中；确认创建后清除草稿。如果设备存储不可用，窗口会保留输入；可创建笔记，或复制内容后点击“放弃这次记录”并确认。清理浏览器数据会移除这份未提交草稿，重要记录请及时创建笔记。

## 高级搜索与保存搜索

关键词之间以空格分隔，所有条件同时满足；匹配不区分大小写。引号中的内容按完整短语匹配。最多 2048 字符、64 个条件，未闭合的引号会提示错误。

| 条件 | 示例 |
|---|---|
| 正文或名称关键词 | `梯度 下降` |
| 完整短语 | `"梯度下降"` |
| 相对路径包含文字 | `path:课程`、`path:"课程 2026"` |
| 标签及其子标签 | `tag:数学`、`#数学` |
| 排除 | `-考试`、`-"考试 真题"`、`-path:归档`、`-tag:完成` |

例如 `path:课程 tag:数学 "梯度下降" -path:归档`。如果要查找字面上的 `path:课程` 或 `-word`，把整个词放进双引号。

“保存搜索”保存当前条件，之后从下拉框重新查询；同名保存会先确认是否更新。每个仓库在此设备最多保存 30 项，移除搜索不会修改笔记。完整备份的工作区会话包含保存搜索，恢复并应用界面设置与工作区时可一并恢复。

组合条件只用于筛选，不显示“全部替换”。全文替换须使用单个普通关键词或引号短语，并保留原有的区分大小写替换规则及版本快照。

## 笔记属性与列表

打开 Markdown 笔记，在右侧信息页点击“笔记属性”。可填写课程、状态、0–100 的掌握程度、复习日期及逗号分隔的标签；清空已填字段可移除它。属性以文件开头的 YAML 区域保存：

```yaml
---
course: "线性代数"
status: "学习中"
mastery: 65
review: "2026-11-01"
tags: ["数学", "复习/重点"]
---
```

也识别中文字段名，以及 `review_date`。支持简单文字、数字、布尔值、日期和列表，不是完整 YAML 编辑器。复杂或重复的目标字段只读，需在源码中修改；未编辑字段、未知结构与正文保留。属性区超过 64 KiB 或缺少结束标记时，表单拒绝写入。属性保存沿用原有的冲突检查和历史版本机制。阅读模式或只读授权下只展示属性。

列表在编辑区内打开，侧栏仍可使用。支持搜索条件、课程文字、精确状态、最低掌握程度，以及“今天及之前待复习”筛选；未设置复习日期的笔记不算到期。按名称、课程、状态、掌握程度、复习日期或修改时间排序，缺失值排在末尾，数字 0 会正常显示。每页最多 100 篇，可翻页。

点击名称打开笔记，点击“属性”查看或编辑该笔记的属性。列表读取失败时可刷新重试；它不运行 Dataview/JavaScript 查询脚本。
