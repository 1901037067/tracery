# Tracery v1.6.0

此版本改进标签栏、双链路径和绘图，同时包含笔记库排序及悬浮画板。

## 下载与升级

下载 `Tracery-1.6.0-win32-x64.zip`，解压完整文件夹，运行 `Tracery.exe`，适用于 Windows 10/11 64 位。无需另装 Node.js；请保留 resources 和 DLL 文件，不要只复制 exe。

升级前备份自己的笔记库和附件，退出旧程序，把新包解压到独立目录再运行。个人笔记格式不变。`SHA256SUMS.txt` 可用于校验下载文件。

## 新增与改进

- 标签头改为紧凑圆角卡片，多标签在独立区域滚动。桌面右侧始终留出专用拖窗区域，不挤占窗口按钮；标签仍支持拖拽排序和下拉切换。
- 笔记库提供文件名、编辑时间和创建时间的正反序排序，按笔记库记住选择。右键文件或文件夹时显示目标描边。
- 图谱缩放以鼠标位置为中心，手动缩放后不再被自动适配打断；小比例隐藏名称，并改善大图谱计算和重绘。
- 绘图保留顶部栏和最左导航栏，画布占满其余区域。工具、样式和图片库悬浮于画布，可分别收起或整体隐藏。
- 绘图中通过主导航、标签页或笔记库切换离开时，未完成内容先保留为本机草稿；可在图片库重新打开。本机草稿不会自动同步到其他设备。

## 修复

- `[[项目/笔记名]]` 等带路径的双链被错误标记为不存在、点击无法跳转。现在支持笔记库根路径、相对路径、文件后缀、别名和标题定位，例如 `[[../资料/笔记.md#章节|说明]]`。有多篇同名笔记时请填写路径以明确目标。
- 绘图选择工具拖动时缺少可见范围：现在显示半透明框选区域和边框，松开后清除拖动范围并保留选中元素的边框。

## 使用范围

Tracery 可完全在本机使用，无需云账户、付费服务器或域名。手机访问需要同一可信局域网，电脑保持运行且不休眠；网页当前可读写电脑笔记库，没有独立只读授权，不要直接开放公网。

当前没有完整手机离线笔记库。手机网页访问、PWA 安装和附近设备同步发现是不同功能。更多操作与排障见 [使用说明](https://github.com/1901037067/tracery#readme)。
