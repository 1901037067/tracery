# 大笔记库使用与排障

笔记库较大时，首次打开需要扫描笔记和建立搜索、标签、链接索引，请等待加载完成。后续打开会复用本地缓存，实际速度取决于笔记总大小、磁盘与电脑性能。

## 日常使用

- 用搜索或 Ctrl+P 查找笔记，无需把所有目录展开。
- 大文件树滚动时只显示当前可见条目，屏幕外的笔记仍保存在笔记库中。
- 完整图谱和全文搜索会随笔记数量与正文大小消耗更多资源。大量附件也会增加扫描和备份时间。

## 搜索、标签或链接结果异常

1. 先确认笔记已经保存，尝试重新打开笔记库。
2. 若仍异常，退出 Tracery，备份笔记库后删除该笔记库里的 .tracery/index.json，再重新打开。这个文件是可重建的索引缓存，不是笔记正文。
3. 若反复重建失败，检查磁盘剩余空间与目录写入权限。不要删除整个 .tracery 文件夹，其中可能含其他本地配置。

缓存保存在自己的电脑上，包含搜索所需的正文副本。共享电脑时，也应保护整个笔记库目录的访问权限。

报告问题时请提供笔记数量、正文总大小、操作系统，以及能否在一个不含私人内容的小笔记库中复现；无需上传个人笔记库。
