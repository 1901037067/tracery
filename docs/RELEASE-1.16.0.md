# Tracery v1.16.0

本次更新集中整理仓库管理、全库视图、笔记属性和绘图界面。

- 笔记列表和全库任务移到最左侧导航栏，铺满工作区；返回编辑区后恢复原有侧栏布局。任务页去掉内层卡片，保留搜索、状态数量、分页、原笔记定位及勾选更新。
- 标签分组横线下移；保存的分组卡片增加数量与操作菜单，绿色实心点表示已打开，灰色空心点表示未打开。
- 大纲当前标题和悬浮标题使用主题色加粗，当前标题左侧显示主题色竖线。
- 仓库管理改为打开、创建双入口。创建仓库可选择存放目录并预览完整路径，拒绝覆盖同名文件夹。
- PDF 摘录窗口重新整理来源、目标核对、摘录表单及底部操作；页码仍需手动确认。
- 笔记属性使用紧凑双列表单，右上角关闭、右下角保存，保留原正文与其他属性。
- 绘图画板覆盖工作区边缘；图片库与颜色样式入口合并为滑动切换控件，整理色板、色号与样式选项，移除顶部取消按钮。可按 Esc 或通过主导航离开；修复保存草稿后隐藏弹窗阻断绘图快捷键的问题。

下载 `Tracery-1.16.0-win32-x64.zip`，解压完整文件夹并运行其中的 `Tracery.exe`，保留随包 DLL、`resources` 和许可文件。Windows x64 包自带运行时，无需安装 Node 或 Electron。`SHA256SUMS.txt` 可用于校验下载文件。

关闭旧程序后再运行新包。笔记与附件继续保存在原仓库，本机草稿、分组和工作区仍属于当前设备；手机访问仍需同网且电脑保持运行。
