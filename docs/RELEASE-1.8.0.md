# Tracery v1.8.0

## 新增与改进

- 标签栏参考浏览器布局：末尾「＋」打开空白标签，标签较多时自动压缩，取消横向滚动；加号与下拉之间保留桌面拖窗空区。
- 新增彩色标签分组，支持改名、选色、折叠展开、拖动标签移入移出、整组换序，以及组内新开标签。分组与空白标签按仓库保存在本机，关闭分组不会删除笔记。
- 未打开笔记或关闭最后一个标签时显示空白起始页，提供新建笔记和快速打开入口。
- 完善实时预览：HTML 下划线、代码块背景与语言标识、基础代码高亮、嵌套引用竖线和层级缩进。
- 新增行内与独立数学公式渲染，支持上下标和矩阵。公式引擎及字体随软件保存，离线可用，点击公式可回到源码编辑。
- Markdown 网页链接显示名称、下划线和外链图标，点击在浏览器打开；编辑当前行时显示链接源码。
- 绘图选框的圆角手柄与四角对齐，缩放与旋转后拖动保持稳定；统一大纲当前标题的悬浮背景。

## 下载与使用

下载 `Tracery-1.8.0-win32-x64.zip` 并完整解压，运行其中的 `Tracery.exe`。无需安装 Node 或 Electron，请保留同目录下的资源与 DLL。校验文件见 `SHA256SUMS.txt`。

升级前可备份整个笔记仓库。笔记和附件保存在自己的电脑里；标签分组、最近颜色等界面状态保存在本机。手机访问需要同一可信局域网且电脑保持运行。更多操作见 [使用说明](https://github.com/1901037067/tracery#readme)。
